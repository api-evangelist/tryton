The MSYS2 project has discontinued building cx-Freeze for the mingw32 platform . We depend on these packages to build our Windows client, and we currently do not have the resources to maintain the required packages for Windows 32-bit ourselves. As a result, we will no longer publish Windows 32-bit builds for new releases of the supported series.
